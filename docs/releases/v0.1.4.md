Fixes fresh Vodafone sign-in when reCAPTCHA is required.

The v0.1.3 navigation hardening could block Google's CAPTCHA frames, causing “Could not connect to the reCAPTCHA service.” VodaLens now permits only documented HTTPS reCAPTCHA paths on exact approved Google hosts, and only inside subframes. Top-level navigation and the token-handoff bridge remain restricted to Vodafone.

- Adds regressions for CAPTCHA scope, host spoofing, ports and path traversal.
- Verified a real disconnect/reconnect: local data erased before Vodafone's revocation HTTP 200; human sign-in completed normally; token-free handoff and native account, usage, history and billing reads succeeded.
- No “Something didn't go as planned” message appeared in the successful reconnect run. Earlier occurrences have not been conclusively attributed to a single cause.
- Temporary metadata-only diagnostics were removed from the installed app and are not included in this release.

Requires Android 16 or newer. Public v0.1.2/v0.1.3 users can update normally using the same release certificate. Download `VodaLens-0.1.4.apk` and verify it using `SHA256SUMS`.

Saved recent-app thumbnails are hidden; normal screenshots remain available. Vodafone refresh-token idle and maximum lifetimes remain unknown. A 30-minute closed-app test is separate from the verified short-interval renewal test; continuous sign-in cannot be promised.
