VodaLens AU brings your Vodafone Australia usage and bills into a simple native Android app.

- Shared data remaining, per-service consumption and daily usage charts.
- Billing-cycle progress compared with data use, plus up to six previous usage cycles where available.
- Current amount due and recent bills, with paid invoices correctly separated from outstanding debt.
- “Last refreshed” date/time on Usage, daily usage and Bills.
- Material You colours, distinct service accents and clear usage-pace indicators.
- On-phone sign-in, encrypted local storage and automatic access-token renewal when available.

Requires Android 16 or newer. Download `VodaLens-0.1.2.apk`; `SHA256SUMS` provides its checksum. This APK is built, tested and signed by GitHub Actions from the release tag. It contains no personal account data or backend credentials.

This independent companion is not affiliated with Vodafone. Carrier reporting delays and historical availability apply. Multi-day session lifetime remains unmeasured; Vodafone may require another sign-in. iOS is not released yet.

The public release uses a dedicated signing certificate. It cannot update an existing development/personal build signed with a different key. Uninstalling that build removes its saved connection and history; no phone changes are performed by this release.
